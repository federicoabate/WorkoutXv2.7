WorkoutX v2.5 — correzioni RPE, RM, Final Drop Set
================================================
Aggiornamento mirato alla precedente build v2.5.

RPE: valori storici contraddittori esclusi dalla scelta; una prestazione
con RPE inferiore e carico/ripetizioni non inferiori prevale per i
suggerimenti di livelli superiori. Storico non riscritto.

RM: i riferimenti reali RIR 0 (massimo carico a pari ripetizioni) vengono
resi coerenti. Le stime tra riferimenti reali sono interpolate; quelle
esterne estrapolate dal riferimento reale più vicino. Scala 1–15 RM
non crescente. Suggerimenti e tabella utilizzano la medesima funzione.

Final Drop Set: un solo set eseguibile, mostrato esclusivamente accanto
all'ultimo set del principale. Il tasto + Set non aggiunge set al Final
Drop Set; eliminazione e modifica del conteggio del suo unico set
impedite. Il salvataggio mantiene i record per singolo esercizio.

Verificati: sintassi JS, integrità ZIP, test di calcolo mirati.
Non effettuato collaudo completo dell'interfaccia su iPad/Safari.
Conservare un backup JSON prima dell'installazione.
